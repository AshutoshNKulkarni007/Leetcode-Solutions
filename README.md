
# LeetCode Solutions in C

A collection of solutions to LeetCode problems implemented in C.
This repository documents my problem-solving practice, algorithmic
thinking, data structures, and coding progress.

## About This Project

This project was created as part of my LeetCode practice and portfolio
development activity.

The repository contains solutions to eight required problems. Each
problem includes a C source file, Markdown documentation, and a screenshot
of the LeetCode submission result.

The goal is to improve my understanding of algorithms, data structures,
complexity analysis, testing, and version control.

## How to Compile and Run

Make sure GCC is installed and available in your terminal.

For example, to compile and run the Two Sum solution:

```powershell
gcc arrays-strings/01-two-sum.c -o two-sum.exe
.\two-sum.exe
```

Repeat the process with the appropriate source file and output
executable name for other programs.

Some LeetCode solutions use the function signature provided by
LeetCode and do not include a `main()` function. Such solutions
must be tested using a separate local test harness or submitted
directly to LeetCode.
